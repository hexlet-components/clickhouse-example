# AGENTS.md

Учебная база доски объявлений для курса ClickHouse на Хекслете. Репозиторий создан из шаблона `hexlet-components/component-template`, общий слой проверок взят из [dev-quality-gates](https://github.com/mokevnin/dev-quality-gates).

## Устройство

- `schema.sql` пересоздаёт базу `board` и её таблицы.
- `data.sql` наполняет таблицы генератором на `numbers()` и хешах номера строки. Масштаб приходит параметром клиента `--param_scale`.
- `examples/*.sql` по файлу на тему курса. Примеры читают `board`, а свои таблицы создают в `board_lab` и удаляют её в конце файла.
- `.env` держит версию сервера для `compose.yaml`, её же берёт CI.

## Правила

- Данные строятся детерминированно. Случайные функции (`rand`, `generateRandom` без сида, `now()` в данных) ломают воспроизводимость ответов.
- Закономерность, на которую опирается пример, проверяется запуском примера на полном масштабе. Малый масштаб из `make test` ловит только ошибки запросов.
- Словарь совпадает с курсом. Имена столбцов (`ad_id`, `visitor_id`, `category`, `city`, `price`) и список категорий берутся из уроков `hexlethq/courses/ru/clickhouse_course`.
- sqruff не ставится. Его диалект ClickHouse не разбирает параметры `{scale:Float64}` и предлагает менять регистр имён функций и типов, а в ClickHouse они чувствительны к регистру. SQL проверяет `make test` на настоящем сервере.
- Сервер 26.8 требует процессор с AVX2. На машине без него локальный прогон идёт на другой версии, например `CLICKHOUSE_VERSION=25.3.9.72 make up`, а итог для 26.8 даёт CI.

## Проверки

`mise run test` с запущенным сервером и `mise run check`. Оба запускаются в CI.
